# Handoff: 마감할인 — 유저 핵심 루프 (탐색 → 예약·결제 → 픽업)

## Overview
동네 전통시장·상점의 **마감 임박 할인(deal)** 상품을 지도/리스트로 찾아 예약·결제하고,
매장에서 QR/픽업번호로 수령하는 모바일 앱의 **유저(구매자) 핵심 흐름**입니다.

이 번들은 다음 6단계 화면을 다룹니다:
`홈(리스트)` → `지도` → `매장 상세` → `상품 상세·예약` → `결제(mock)` → `예약 완료` → `QR 픽업`

## About the Design Files
이 폴더의 `마감할인.dc.html` 은 **HTML로 만든 디자인 레퍼런스(프로토타입)** 입니다 — 의도한
외형·레이아웃·동작을 보여주는 목업이며, **그대로 복붙해서 배포하는 코드가 아닙니다.**
할 일은 이 디자인을 **대상 레포의 기존 환경(React 19 + TS + Tailwind v4)에서, 그 레포의
기존 패턴·라이브러리로 다시 구현**하는 것입니다. 이 HTML은 “정답 스펙”이지 “정답 코드”가 아닙니다.

> 이 HTML은 DC 런타임(`support.js`)과 CDN Pretendard를 사용하므로, 로컬에서 열 때는
> 정적 서버(`npx serve .` 등)로 띄우면 렌더됩니다. **레퍼런스 확인용**이며, 구현 기준은 이 README 입니다.

## Fidelity
**High-fidelity (hifi).** 최종 색상·타이포·간격·인터랙션이 반영된 목업입니다. 대상 코드베이스의
컴포넌트/유틸로 **픽셀에 가깝게 재현**하세요. (단, 아래 “Design Tokens”의 실제 값을 기준으로 삼으세요.)

## Screens / Views

각 화면은 상단 상태바(9:41 / 5G / 배터리) + 콘텐츠 + (홈/지도/마이는) 하단 탭바 구조. 탭바 항목:
**홈 · 지도 · 알림 · 마이**, 활성색 `#1F5140` + 하단 5px 점.

### 1. 홈 (리스트) — route `/`
- **Purpose:** 내 위치 반경(2km) 내 마감세일을 가까운 순/마감임박/할인율로 정렬해 리스트로 탐색.
- **Layout (위→아래):**
  1. 위치 헤더: 좌측 `● 회현동 ▾`(그린 점 7px), 우측 원형 지도 버튼(`◎`, 38px, 보더 `#E7E2D9`).
  2. 히어로 카피: `오늘 마감,\n동네에서 담아요` (27/700). 아래 `반경 2km · 지금 마감세일 12곳`(12곳=그린 강조).
  3. 정렬 필터칩 가로 스크롤: 활성=`가까운 순`(ink `#1B1A17` 채움/흰 텍스트), 나머지=흰 배경+보더 칩 (`마감임박`,`할인율`,`청과`).
  4. 리스트(흰 배경): 각 행 = [썸네일 72×72 r12] + [상점명·거리 / 상품명 / 할인율·원가취소선·최종가] + [우측: 마감시각(mono, 임박 시 `#C0392B`) / 남은 수량]. 행 구분선 `#F1EDE5`.
- **데이터 예시(4행):** 행복베이커리·크로와상 5,000→2,500(50%)·320m·마감21:00·남은5개 / 신선마트·국산 우유 1L 3,200→1,900(40%)·540m·22:00·8개 / 초록상회·유기농 쌈채소 6,000→3,500(42%)·780m·19:30(임박)·3개 / 남문수산·손질 고등어 2손 12,000→7,000(42%)·1.1km·20:00·2개.
- **행 클릭 →** 매장 상세(`/stores/:id`) 또는 상품 상세(`/sales/:id`). (권장: 행 전체 → 상품 상세)

### 2. 지도 (전체화면) — route `/map`
- **Purpose:** 같은 세일 데이터를 지도 위 가격 핀으로 탐색. `react-kakao-maps-sdk` 사용.
- **Layout:** 전체 지도. 상단 플로팅 검색바(흰 카드 r14, `⌕ 지역·매장 검색`) + 그 아래 필터칩(전체/베이커리/청과). 지도 위 **가격 핀**: 선택 핀 = 그린 채움(`2,500원`), 나머지 = 흰 배경+보더. 현재위치 = 파란 점(`#2F6DF0`, 흰 테두리 + 반투명 링). 하단 **peek 카드**(썸네일+상점명+`마감임박` 뱃지+거리·수량+가격+`›`).
- **핀/카드 클릭 →** 매장·상품 상세.

### 3. 매장 상세 — route `/stores/:id`
- **Purpose:** 한 매장의 정보 + 판매 중인 마감세일 목록.
- **Layout:** 헤더(`‹` / `매장 상세` / 공유 `⤴`). 상단 이미지 200px. 매장명 22/700 + 카테고리·거리·주소 + `★ 4.8 (126) · 오늘 21:00 마감` + 우측 찜 하트(원형 버튼, 활성 `#C0392B`). 구분선. `판매 중인 마감세일` 섹션 → 상품 행들: [썸네일 60] + [상품명 / 할인율·원가·최종가 / 남은 수량] + [우측 `예약` 버튼(그린 채움 r10)]. 품절 행은 `opacity .5` + 버튼 `마감`(회색).
- **`예약` →** 상품 상세(`/sales/:id`).

### 4. 상품 상세 · 예약 — route `/sales/:id`
- **Purpose:** 상품 확인 + 수량 선택 + 예약·결제 진입. 마감까지 실시간 카운트다운.
- **Layout:** 헤더(`‹`/`상품 상세`/찜 `♡`). 이미지 220px. 상점명·거리 → 상품명 23/700 → 가격줄(그린 `50%` 칩 + 원가 취소선 15px + 최종가 27/800). **마감 카운트다운 배너**(배경 `#FBECE9`, 좌 `마감까지`/우 `01:23:45` mono, 색 `#C0392B`). 안내줄: `◷ 픽업 가능 시간 · 오늘 18:00~21:00`, `▦ 남은 수량 5개 · 1인 최대 3개`. 구분선. **수량 스테퍼**(− / 1 / +, +는 ink 보더 강조). 하단 고정 바: `총 결제금액 2,500원` + CTA `예약하고 결제하기`(그린 풀폭 r14).
- **CTA →** 결제 화면.

### 5. 결제 (mock) — checkout (route 예: `/sales/:id/checkout` 또는 결제 시트)
- **Purpose:** 금액 확인 + 결제수단 선택 + 결제(현재 mock). 결제 성공 시 주문이 `reserved → paid`, QR/픽업번호 발급(`order.paid` 이벤트).
- **Layout:** 헤더(`‹ 결제`). 주문 상품 카드(썸네일+`버터 크로와상 × 1`+매장·거리). **결제 금액 카드**: `상품 금액 5,000원` / `마감 할인 -2,500원`(그린) / 구분선 / `최종 결제금액 2,500원`(20/800). 정보 배너(그린 틴트 `#E7EFE9`): `◷ 결제 후 10분 안에 매장에서 픽업해 주세요`. 결제수단 카드: `결제수단 › 간편결제 (mock)`. 하단 고정 CTA `2,500원 결제하기`.
- **CTA →** 예약 완료.

### 6. 예약 완료 — route `/orders/:id` (완료 상태)
- **Purpose:** 예약 성공 확인 + 픽업번호 노출 + QR/내 예약 진입.
- **Layout(세로 중앙):** 체크 원형(76px, `#E7EFE9` 배경 / 그린 `✓`). `예약이 완료됐어요` 23/700. 안내 2줄(`픽업 시간 안에 방문해 픽업번호나 QR을 보여주세요`). 요약 카드(`#F7F4EF`): `픽업번호 A-142`(20/800 mono) / 구분선 / `버터 크로와상 × 1 … 2,500원`. 하단: CTA `QR 코드 보기`(그린) + 아웃라인 `내 예약 보기`.

### 7. QR 픽업 — route `/orders/:id` (QR 뷰)
- **Purpose:** 매장에서 스캔할 QR + 픽업번호 표시.
- **Layout:** 헤더(`‹ 픽업 QR`). 안내 `매장에서 이 QR을 보여주세요`. **QR 카드**(흰 r22, 보더, 소프트 섀도) — `qrcode.react` 로 주문 토큰 렌더(목업은 184px 그리드 플레이스홀더). 아래 `픽업번호 A-142`(30/800 mono). 주문 요약 카드(썸네일+매장+상품+가격). 하단 보조 버튼 `픽업번호로 확인하기`.

## Interactions & Behavior
- **네비게이션 플로우:** 홈/지도 → 매장 → 상품 → (예약하고 결제) → 결제 → (결제하기) → 예약 완료 → (QR 코드 보기) → QR. 뒤로가기 `‹` 는 이전 화면.
- **실시간 카운트다운(상품 상세):** `마감시각 - now` 를 `HH:MM:SS` 로 1초마다 갱신. 0 도달 시 품절/마감 처리. (목업은 `setInterval` 로 구현되어 있음.)
- **수량 스테퍼:** 1 ~ `min(남은수량, 1인 최대 3)`. 하단 총액은 `단가 × 수량` 실시간 반영.
- **탭/버튼 상태:** CTA·`예약` 버튼 hover/press 시 `#163A2E`. 활성 탭 그린 + 점. 찜 토글(빈 하트 `♡` ↔ 채운 하트 `♥`/`#C0392B`).
- **품절/마감:** 리스트·매장 상세에서 해당 항목 `opacity .5`, 버튼 `마감`(비활성).
- **예약 만료:** 결제 안 하면 10분 후 예약 만료 + 재고 원복(백엔드 sweep). 프론트는 만료 안내/재조회.

## State Management
- **서버 상태 (TanStack Query v5):**
  - `useNearbySales({lat,lng,radius,category,sort})` → 홈/지도 리스트
  - `useStore(id)` / `useStoreSales(id)` → 매장 상세
  - `useSale(id)` → 상품 상세(할인율 포함)
  - `createOrder` (mutation, 원자 조건부 재고 차감) / `payOrder` (mutation, mock) / `useOrder(id)`
- **클라이언트 상태:** 수량(로컬), 선택 카테고리·정렬(URL 쿼리 권장), 찜 토글(낙관적 업데이트 후 Favorite API), 인증 stub(zustand `authStore`: `{userId, ownerId, role}`).
- **실시간(SSE):** `useNotificationStream(userId)` 로 새 알림 시 관련 쿼리 무효화(핵심 루프 밖이지만 결제 완료 알림과 연동).
